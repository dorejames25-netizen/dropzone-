# Style standard

The six plates of the first section (Metro platform v2 and rooms 2 to 6) are the quality bar for every background plate. New art is judged against it.

## Format

- 16:9, **2752 x 1536** PNG, one clean image per plate.
- No characters, people, creatures, text, title cards, borders, UI or logos baked in.
- Name files `<room>_v1.png`. A locked version is never overwritten, new work becomes `v2`.

## Look

- Thick dark ink outlines over painted, grimy texture (cracked stone, peeling plaster, wet tile, splatter).
- Hard-edged shading with sharp shadow steps. Near-black shadows, very high contrast.
- One key colour per room. Scene 1 key is **deep magenta**, with **emerald green and teal** as the second colour.
- **Modern lighting only**: LED strips, neon tubes, recessed spotlights, light panels, caged work lights, holographic fixtures. Gothic is the architecture, not the lamps.
- Wet, reflective floors that pick up the room's glow. Coloured fog near openings.
- Gothic architecture: arches, ribbed vaults, iron brackets, gargoyles. Cyberpunk through lighting and screens, not clutter.

## Built for the game

- A wide, clear floor for the player, ending at a visible edge (a yellow line, a wall).
- Big foreground objects the player can walk behind (pillars, arches), drawn as clean shapes so they can be cut out.
- Furniture the player cannot cross, placed so it does not block the main path.
- Blank dark screens, signs and shafts for animation, with only a thin glowing frame.
- At least two exits (stairs, tunnels, doors) visible in the plate.

## Never

- Oil lanterns, gas lamps, candles or torches (old-fashioned lighting).
- Real brands, logos, game or film characters, or real-world religious symbols.
- Falling code or faces baked into the plate. Those are separate animation layers.

## Checklist before locking a plate

1. Floor is clear and readable at game size.
2. Walk-behind objects separate cleanly.
3. Animation slots are blank.
4. Colours match the room's key colour and the shared palette.
5. Plan image made (walkable, blocked, walk-behind, animation, exits).
